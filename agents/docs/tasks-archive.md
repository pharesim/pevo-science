The structural fix is not "patch the verify" but "replace EmbeddedNode's HTTP-cache architecture with a real in-process IPFS node via `github.com/ipfs/boxo`" — the original design intent (pinner ships as a single Go binary that embeds the IPFS node, one file to run for third-party libraries helping share PEvO content).
